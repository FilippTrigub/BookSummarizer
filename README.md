## Audio-Book-Summarizer

No time to read, so you're listening to audiobooks? Me too. The problem: how to take notes?

This is where this AI comes in. Just upload an MP3 or WAV file and a summary will be sent to your email address.

Cherry on top? You get both a summary by chapter and an ultra-short summary for the entire book at no extra cost!

For more information don't hesitate to reach out!

_Filipp Trigub_

## Technical specifications

The bot uses OpenAI whisper for speech-to-text and GPT-3.5-16k generation.

Flutter and Dart is used for the UI.

Cloud Deployment and CI/CD is done with TerraForm and with GitHub to Azure. 

A version is available on my [website](https://www.trigub.tech).
